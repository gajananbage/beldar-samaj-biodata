# बेलदार समाज परिचय पत्र जनरेटर 🙏

**श्री गणेशाय नमः** - हे टूल बेलदार समाजासाठी परिचय पत्र (बायोडाटा) तयार करण्यासाठी आहे. A4 PDF/JPEG डाउनलोड, प्रिंट, आणि मराठी UI सह.

## फीचर्स ✨
- **पूर्ण मराठी इंटरफेस** - सोपे फिलअप
- **फोटो अपलोड** - पासपोर्ट साइज प्रीव्ह्यू
- **A4 परफेक्ट PDF/JPEG** - बग-फ्री एक्सपोर्ट
- **dd/mm/yy डेट फॉरमॅट** - भारतीय स्टाइल
- **मोबाईल + डेस्कटॉप** - रिस्पॉन्सिव्ह
- **नो इन्स्टॉलेशन** - डायरेक्ट ब्राउजर
